# Yu-Gi-Oh! Academy

## Descripción

Yu-Gi-Oh! Academy es una aplicación web educativa cuyo objetivo es ayudar a los jugadores a aprender y consultar información sobre el juego de cartas Yu-Gi-Oh!.

La aplicación ofrecerá información sobre las reglas, los tipos de cartas, las invocaciones, las handtraps y las estrategias de victoria.

## Objetivos

- Aprender las reglas básicas del juego.
- Consultar un catálogo de cartas.
- Conocer los diferentes tipos de invocación.
- Comprender el funcionamiento de las handtraps.
- Estudiar estrategias como OTK y FTK.
- Ofrecer una interfaz sencilla, adaptable y accesible.

## Tecnologías

- **Frontend:** Angular
- **Lenguajes:** TypeScript, HTML y CSS
- **Control de versiones:** Git
- **Repositorio remoto:** GitHub

Las tecnologías de backend y base de datos se concretarán cuando se implemente esa parte del proyecto.

## Funcionalidades previstas

- Página de inicio.
- Catálogo de cartas.
- Detalle de cada carta.
- Guías de aprendizaje.
- Sección de estrategias.
- Registro e inicio de sesión.
- Apartado de ayuda y perfil.
- Interfaz con tema oscuro.

## Instalación y ejecución

### Requisitos

- Node.js y npm.
- Angular CLI.
- Visual Studio Code (recomendado).

### Pasos

1. Clonar el repositorio.
2. Entrar en la carpeta del proyecto.
3. Instalar las dependencias.
4. Iniciar el servidor de desarrollo.

```bash
git clone URL_DEL_REPOSITORIO
cd yugioh-academy
npm install
ng serve -o
```

Sustituye `URL_DEL_REPOSITORIO` por la URL real del repositorio de GitHub.
